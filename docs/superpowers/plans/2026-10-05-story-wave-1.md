# Story Pages Wave 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Manuel chose Native) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the warmstart, bandera, mesa, doorman and asedio demos into story pages built like Compuerta's, each with a bet a visitor can lose.

**Architecture:** The shared pieces (story components, `FlowDiagram`, `OutcomeTape`, `copy-lint`) come from the hub with `pnpm brand:sync`. Each project gets its own `lib/experience/story.ts` (EN/ES copy as typed data), a story scene, and a page rebuilt in Compuerta's section order. Where a bet can't be lost with today's controls, the engine gets the smallest change that makes it losable, in TS and Python, pinned by a shared fixture.

**Tech Stack:** Next.js 16, TypeScript strict, Tailwind v4, Vitest, pytest (uv), node:test in the hub.

**Spec:** `docs/superpowers/specs/2026-10-04-project-story-pages-design.md`. Master plan: `docs/superpowers/plans/2026-10-05-story-pages-rollout.md`. Reference implementation: `../compuerta` on `main` after compuerta#4 merges (`app/[lang]/app/page.tsx`, `lib/experience/story.ts`, `story.test.ts`, `scene-state.ts`, `compuerta-scene.tsx`).

## Global Constraints

- Prerequisites on `main`: hub#5 and compuerta#4 (Wave 0), plus backup PR #1 of each of the 5 repos. Branch per repo: `feat/story-page` from `origin/main`. Hub branch: `feat/story-wave-1`.
- Page order: 00 hook · 01 analogy (with dictionary) · Why I built it (hidden while empty) · 02 try it (bet first) · 03 compare (after playback) · 04 where it fits · 05 what it proves · For engineers (folded).
- Copy: same shape in EN and ES; `lintStory` clean; no brands; first person; one concrete detail per section. The ES key lines below are approved drafts (Manuel approved the analogies on 2026-10-05). The EN copy is written at implementation, following the same lines.
- `why.text` stays `""` until Manuel sends it.
- Engine changes land in TS and Python together and are pinned by a fixture both sides read. No engine change without a failing test first.
- Money in integer cents. No `any`, no `@ts-ignore`.
- A classifier deny is a wall: stop and report BLOCKED.

## Review Focus

1. **Bet that can't lose.** Every project gets a sweep test over its main control proving both answers are reachable from the defaults (Tasks 2–6, step "sweep").
2. **Bet text out of sync with controls.** `question` is a function of every control the grade reads (each `story.test.ts`).
3. **Tape that doesn't match the result.** The final tape counts equal the engine's totals (each scene-state test).
4. **Reset to a trivial default.** The `reset` handler must restore the non-trivial defaults, not the old ones (each page; checked in the browser step).
5. **Mobile.** 390px with no horizontal overflow and every diagram node visible (each verify step).
