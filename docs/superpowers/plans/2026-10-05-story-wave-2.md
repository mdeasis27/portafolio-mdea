# Story Pages Wave 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Manuel chose Native) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn agente-riesgo, kyc-antifraude, identidad-360, radar-proveedores and agente-cobranzas into story pages built like Compuerta's, each with a bet a visitor can lose.

**Architecture:** Same page and shared pieces as Wave 1 (`pnpm brand:sync` from the hub). The difference: every Wave 2 engine decides **one case** from a few booleans, so no control can make a bet go both ways. Each project gets a **fixed batch of fictional cases** in `lib/experience/batch.ts`, run through the project's **existing decision function** (or a small graded version of it), and a single slider that grades the batch. The tape is one square per case.

**Tech Stack:** Next.js 16, TypeScript strict, Tailwind v4. Tests: `node:test` through `tsx --test` (vitest only in identidad-360, where it already is). No Python: none of the five has a backend, so there is no parity fixture to keep.

**Spec:** `docs/superpowers/specs/2026-10-04-project-story-pages-design.md`. Master plan: `2026-10-05-story-pages-rollout.md`. References: `../compuerta` and the five Wave 1 repos on `main`.

## Global Constraints

- Prerequisites on `main`: backup PR #2 of each of the 5 repos. Branch per repo: `feat/story-page` from `origin/main`. Hub branch: `feat/story-wave-2`.
- Page order, copy rules, `why.text = ""`, `lintStory` clean, no brands, no `any`/`@ts-ignore`, money in integer cents: as in Wave 1.
- The batch is fictional and labelled so in "For engineers". Every case goes through the real decision function; the batch only chooses the inputs.
- Old single-case controls (checkboxes, selects, presets) are removed from the page. The existing `runExperience` adapter and its tests stay, so the public API and old tests don't change.
- `brand:sync` script is added where missing (agente-riesgo, identidad-360, agente-cobranzas): `node ../portafolio-mdea/scripts/brand-sync.mjs`.
- `test` script runs every `lib/experience/*.test.ts` (today some tests aren't wired in, e.g. radar's and cobranzas' `story.test.ts`).
- A classifier deny is a wall: stop and report BLOCKED.

## Review Focus

1. **Bet that can't lose:** a sweep test per project over its slider proving both answers from the defaults.
2. **Bet text out of sync:** `question` is a function of the slider value.
3. **Tape vs result:** final tape counts equal the batch totals.
4. **Reset:** restores the new defaults.
5. **Fictional batch honesty:** copy never presents the batch as real customers; "For engineers" says it is a fixed fictional set.
6. **Mobile:** 390px, no horizontal overflow.
